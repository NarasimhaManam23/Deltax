| Pacing Diagnostic | Symptom | Tactical Correction |

### 3. Subject Weakness Diagnosis
Count your incorrect answers across sections to identify subject deficiencies:
* **Programming Weakness ($> 4$ errors in Q1–Q14)**:
  - *Root Cause*: Compiler sequence points, prefix vs postfix increment execution order, pointer dereferencing nuances (`*p++` vs `(*p)++`), or string null-termination mechanics.
  - *Remedy*: Study `01_ROUND_1_MCQ/study_notes_programming_dsa.md` Modules 1 & 2.
* **DSA Weakness ($> 3$ errors in Q15–Q26)**:
  - *Root Cause*: Conflating average vs worst-case complexities (e.g., QuickSort vs MergeSort), BST properties, or heap array indices.
  - *Remedy*: Study `05_CHEAT_SHEETS/programming_and_dsa_cheatsheets.md`.
* **Networks Weakness ($> 2$ errors in Q27–Q34)**:
  - *Root Cause*: Handshake packet sequences, HTTP status code nuances (401 vs 403), or port mapping.
  - *Remedy*: Review `01_ROUND_1_MCQ/study_notes_networks_cybersecurity.md` Module 1 & 2.
* **Microprocessors Weakness ($> 2$ errors in Q35–Q40)**:
  - *Root Cause*: Forgetting vector calculation formulas ($N \times 8 \implies \text{Hex}$), 8085 flag register bit updates (`INR` does NOT affect Carry!), or addressing mode definitions.
  - *Remedy*: Review `01_ROUND_1_MCQ/study_notes_microprocessors_arch.md`.
* **Cybersecurity / DBMS / OS Weakness ($> 2$ errors in Q41–Q50)**:
  - *Root Cause*: Hashing vs Encryption differences, CSRF vs XSS definitions, Coffman conditions, or SQL `HAVING` vs `WHERE`.
  - *Remedy*: Review `01_ROUND_1_MCQ/study_notes_oop_dbms_os.md`.
